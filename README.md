# vxtension

## 실행

Python 3.11 이상(Tk 포함)과 FFmpeg·FFprobe를 설치하고, FFmpeg의 `bin` 폴더를 PATH에 등록합니다. 프로젝트 폴더에서 실행하세요.

```powershell
python -m vxtension
```

## 사용법

1. **영상 추가**에서 변환할 파일을 선택합니다.
2. **저장 폴더**를 선택합니다. 다음 실행에도 이 위치를 기억합니다.
3. **출력 형식**을 선택합니다. 잘 모르겠다면 기본 설정으로 시작하세요.
4. 파일 분석이 끝나면 **변환 시작**을 누릅니다.

완료된 항목을 두 번 누르면 결과 정보를 볼 수 있습니다. 원본은 유지되고 `_converted`가 붙은 새 파일이 생성됩니다. 중단하려면 **취소**를 누르세요.
